# 人类指挥 Agent 白皮书

一本给**人类**用的参考书：怎样把 Agent 用在刀刃上——怎样下达任务、怎样追加约束、怎样验收、怎样把一次纠正沉淀成长期能力。

它不是 Agent 的操作手册（那是规则与技能的事），而是**人**这一侧的方法论。

## 怎么用

- 第一次读：[00 心智模型](00-心智模型.md) → [01 开场五要素](01-开场五要素.md) → [09 模板库](09-模板库.md)。
- 任务已在跑、想少踩坑：看 [02 需求变更与追加](02-需求变更与追加.md) 与 [08 反模式清单](08-反模式清单.md)。
- 想提升长期效率：[05 反馈与纠正](05-反馈与纠正.md)、[07 并行与委派](07-并行与委派.md)。
- 想看真实素材：[10 案例库](10-本次案例复盘.md)。案例中的历史记录与本次验证范围分别标注。
- 从重复故障练习能力修复：[17](17-复盘到实际修复.md) → [18](18-长期积累与修订.md)。
- 完整任务生命周期：01 定义 → 03 假设与授权 → 07 组织 → 06 验收 → 15 恢复 → 17 修复 → 16/18 持续验证。
